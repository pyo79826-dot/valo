# TACLOG

VALORANT向けの作戦メモ・試合記録アプリの初期版です。

## 現在の機能
- 作戦メモ
- プレイヤーメモ
- クイックタグ
- 試合スコア記録
- ラウンドごとの作戦ログ
- 試合履歴保存
- ラッシュ/ラーク/サイト傾向の簡易統計
- コンパクト表示
- localStorageによる端末内保存
- PC / スマホ対応

## 画面
- 作戦メモ
- 試合
- 履歴
- 統計
- 設定

## 起動
`index.html` をブラウザで開くだけでも動作します。

ローカルサーバーを使う場合は、任意の静的HTTPサーバーでこのフォルダを配信してください。

## デザイン
黒を基調に暗めの赤をアクセントとして使った、タクティカル系のオリジナルUIです。
